🔑 What you'll learn
• man pages: NAME, SYNOPSIS, searching with /word and quitting with q
• Manual sections: man 5 crontab vs man crontab
• --help for quick flags, and when to use man instead
• whatis and man -k (apropos) to find a command by keyword
• type vs which: builtins, aliases and program files; help cd
• history, !number, sudo !!, Ctrl+R and HISTTIMEFORMAT
• Tab completion
• Fixing a full disk on an offline EC2 Jenkins agent with logrotate

🧾 Cheat sheet (copy & practice)
man ls
man 5 crontab
whatis crontab
ls --help | head -3
ls --help | grep -- -h,
whatis ls
man -k "copy files"
apropos "directory contents"
type cd
type ll
type -a ls
type -t cd
which -a python3
help cd
history 5
!498
sudo !!
history | grep systemctl
HISTTIMEFORMAT="%F %T  "
man -k rotate
logrotate --help
sudo logrotate -d /etc/logrotate.d/nginx
sudo logrotate -f /etc/logrotate.d/nginx
